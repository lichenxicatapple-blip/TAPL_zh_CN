\textbf{18.11.1 解答}

先让 \texttt{get} 和 \texttt{set} 都递增访问计数：

\begin{lstlisting}
instrCounterClass =
  lambda r:InstrCounterRep.
  lambda self:Unit->InstrCounter.
  lambda _:Unit.
    let super = setCounterClass r self unit in
      {get = lambda _:Unit.
               (r.a := succ(!(r.a)); super.get unit),
       set = lambda i:Nat.
               (r.a := succ(!(r.a)); super.set i),
       inc = super.inc,
       accesses = lambda _:Unit. !(r.a)};
\end{lstlisting}

加入 \texttt{reset} 的子类如下：

\begin{lstlisting}
ResetInstrCounter =
  {get:Unit->Nat, set:Nat->Unit, inc:Unit->Unit,
   accesses:Unit->Nat, reset:Unit->Unit};

resetInstrCounterClass =
  lambda r:InstrCounterRep.
  lambda self:Unit->ResetInstrCounter.
  lambda _:Unit.
    let super = instrCounterClass r self unit in
      {get = super.get,
       set = super.set,
       inc = super.inc,
       accesses = super.accesses,
       reset = lambda _:Unit. r.x := 0};
\end{lstlisting}

最后加入备份功能，并给出对象生成器：

\begin{lstlisting}
BackupInstrCounter =
  {get:Unit->Nat, set:Nat->Unit, inc:Unit->Unit,
   accesses:Unit->Nat, backup:Unit->Unit, reset:Unit->Unit};

BackupInstrCounterRep =
  {x:Ref Nat, a:Ref Nat, b:Ref Nat};

backupInstrCounterClass =
  lambda r:BackupInstrCounterRep.
  lambda self:Unit->BackupInstrCounter.
  lambda _:Unit.
    let super = resetInstrCounterClass r self unit in
      {get = super.get,
       set = super.set,
       inc = super.inc,
       accesses = super.accesses,
       reset = lambda _:Unit. r.x := !(r.b),
       backup = lambda _:Unit. r.b := !(r.x)};

newBackupInstrCounter =
  lambda _:Unit.
    let r = {x=ref 1, a=ref 0, b=ref 0} in
      fix (backupInstrCounterClass r) unit;
\end{lstlisting}

\textbf{18.13.1 解答}

可以利用引用的别名关系检验对象身份。每创建一个对象，就分配一条专属的
\texttt{Ref Nat} 身份标记；同一对象返回同一条引用，不同对象返回不同引用。
本语言虽不能直接比较引用，却可以通过先写后读判断它们是否指向同一个单元。

内部表示用 \texttt{id} 实例变量保存这条标记。实例变量本身也用引用单元
表示，所以 \texttt{id} 字段为 \texttt{Ref (Ref Nat)}：外层引用是实例变量，
内层引用才是身份标记。

\begin{lstlisting}
IdCounterRep = {x:Ref Nat, id:Ref (Ref Nat)};
IdCounter =
  {get:Unit->Nat, inc:Unit->Unit, id:Unit->(Ref Nat)};
idCounterClass =
  lambda r:IdCounterRep.
    {get = lambda _:Unit. !(r.x),
     inc = lambda _:Unit. r.x := succ(!(r.x)),
     id = lambda _:Unit. !(r.id)};
\end{lstlisting}

\texttt{id} 方法解引用外层的实例变量，返回其中保存的身份标记。
\texttt{sameObject} 接受两个具有 \texttt{id} 方法的对象，并检查它们返回的
引用是否指向同一个单元：

\begin{lstlisting}
sameObject =
  lambda a:{id:Unit->(Ref Nat)}.
  lambda b:{id:Unit->(Ref Nat)}.
    ((b.id unit) := 1;
     (a.id unit) := 0;
     iszero (!(b.id unit)));
\end{lstlisting}

具体做法是：先通过对象 \texttt{b} 的身份标记写入 \texttt{1}，再通过对象
\texttt{a} 的身份标记写入 \texttt{0}，最后读取 \texttt{b} 的身份标记。若
两者是同一对象，后一次写入会把同一单元改为 \texttt{0}，函数返回
\texttt{true}；若它们是不同对象，\texttt{b} 的单元仍保存 \texttt{1}，函数
返回 \texttt{false}。

\translatornote{双层引用并非判断对象身份所必需。作者在这里沿用本章的实例
变量编码：\texttt{id} 的值是一条 \texttt{Ref Nat} 身份标记，而实例变量
本身又用引用单元保存，因而得到 \texttt{Ref (Ref Nat)}。若直接把身份标记
放进内部表示，可将字段改为 \texttt{id:Ref Nat}，并令 \texttt{id} 方法返回
\texttt{r.id}；\texttt{sameObject} 无须改变。}
